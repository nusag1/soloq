# 幸とソロQ

ソロキュー（ひとりでのランクマッチ）が、ちょっとさみしくないように。2人の幸（ひなた・みお）がとなりで反応してくれる、スマホ向けのおともアプリです。

- 使う：https://nusag1.github.io/soloq/
- スマホのホーム画面に追加すると、アプリのように使えます（PCの2枚目のモニターでも使えます）
- データはこの端末のブラウザ（localStorage）の中だけ。Riot ID も含めて、どこにも送りません。設定から JSON で書き出し・読み込みができます
- 音声：VOICEVOX:春日部つむぎ（ひなた）、VOICEVOX:冥鳴ひまり（みお）
- BGM：幸とソロQ オリジナル（開発部）。サンプルや外部の音源を使わず、コードだけで作ったチルな曲です
- Riot Games とは関係のない、個人のファンメイドのツールです

## できること
- **戦績**：試合が終わったら1画面で記録。ふつうは「勝ち → テーマ○ → 記録する」の3タップ（RR はいつもの値、エージェント・マップは前回のまま）。直前の記録は取り消し・直しができる。期間ごとの勝率・RR・マップ別・エージェント別。tracker.gg のプロフィールを開くボタン（設定で Riot ID を入れたとき）
- **今日のセッション**：何試合まで（上限）と RR の目標を決めて始める。セッションの RR の線、日ごとの RR の線。上限に届いたら「ここまでにしませんか」。終えると講評（結果・目標・テーマ・良かったマップ・連敗などから文を組み立てる）
- **1試合1テーマ**：試合の前にテーマをひとつ選び、試合のあとに ○△× を付ける。テーマごとの達成率
- **幸の反応**：記録するたびに、勝ち・負け・連勝・連敗・テーマ・RR の目標・上限などに合わせて、文字と声で反応（ラジオ再生中は文字だけ）
- **ラジオ**：キュー待ち・エージェント選択・試合のあいだに聞く、1本1分くらいのおしゃべり10本（ラウンド中は止める前提）
- **BGM**：キュー待ちに流しておける、オリジナルの lo-fi／チル 5曲（夜のキュー待ち・雨のレンジ・朝のウォームアップ・勝ったあとの帰り道・連敗のあとの深呼吸、各2〜3分でループ）。ラジオの画面で一覧・再生・次へ・1曲リピート／順番に／シャッフル・BGMだけの音量。「今日」の画面にも小さな 🎵 ボタン。幸の声やラジオが鳴るあいだは BGM を 25% に下げて、終わったら戻す（iPhone は音量を変えられないので、そのあいだ一時停止して続きから再開）。ロック画面のボタンは、あとから流したほうを動かす

## しくみメモ（開発用）
- `index.html`（見た目）＋ `app.js`（中身）＋ `sw.js`・`manifest.webmanifest`（PWA。`tools/add_pwa.py` で作ったあと、`SHELL` に app.js などを足した）
- 保存は localStorage の `soloq.v1`：`matches[]`（`{id, ts, result, rr, agent, map, k, d, a, theme, mark, session}`）、`sessions[]`（`{id, start, end, cap, goal, review}`）、`settings` など
- 1日の区切りは朝5時（設定で変えられる）
- **戦績は手入力**（2026-10-22 白さん決定。自動取り込みはしない）。ふつうは「勝ち → テーマ○ → 記録する」の3タップ。RR は結果ごとに最近10試合の真ん中の値が入り、チップは最近よく出る値。エージェント・マップは前回のまま、エージェントはよく使う順。記録のあとに「取り消す」「直す」
- **声**：せりふは `voice/lines.json`（ラジオ `radio[]` と反応 `reactions.<種類>[]`）。PC3 で `python -X utf8 tools/make_voice.py` を実行すると、変わったものだけ `audio/<id>.mp3`（モノラル 24kHz 32kbps）と `audio/index.json`（秒数）を作り直す。VOICEVOX ENGINE は中で起こして止める
- 読み上げ用に英字はカタカナで書く（RR→アールアール）。個人の情報・政治的な話は入れない
- テスト用：`window.__soloq`（状態と主な関数）
- `sw.js` を変えたら `VERSION` を上げる
- **BGM**：`python -X utf8 tools/make_bgm.py [曲id…]` で `bgm/<id>.mp3`（ステレオ 44.1kHz 96kbps）と `bgm/index.json` を作り直す。numpy だけで合成（FM のエレピ、ベース、ノイズのドラム、パッド、ベル／カリンバ／フルート、レコードのぷちぷち、雨）。全部を輪っかのバッファに書くので、ループしても切れ目がない。乱数の種は固定なので同じ曲になる。-16 LUFS・ピーク -1.5dB 以下にそろえる
- BGM の MP3 は `sw.js` で先に入れない（約9MB）。一度流した曲だけ裏で丸ごと取って `soloq-bgm-1` キャッシュにしまい、Range には切り出して返す。曲を作り直したら `BGM_CACHE` の数字を上げる
